# 📚 Documentação do Projeto

## 📌 O que é esta pasta?
Esta pasta reúne toda a documentação do projeto, servindo como base para entender o contexto, o planejamento e a evolução da solução.

## 📂 O que deve ser colocado aqui?
- Plano de ação
- Relatórios parcial e final
- Requisitos funcionais e não funcionais
- Diagramas
- Esboços de telas
- Referencial teórico
- Anotações importantes do projeto

### Exemplos de arquivos:
- `plano-de-acao.md`
- `requisitos.md`
- `relatorio-parcial.pdf`
- `relatorio-final.pdf`
- `diagramas/fluxo-solicitacoes.png`

## 🧠 Boas práticas
- Organize os arquivos por tipo e finalidade.
- Use nomes claros e padronizados.
- Mantenha documentos atualizados conforme o projeto evolui.
- Sempre que possível, registre decisões importantes por escrito.
- Evite arquivos duplicados ou versões com nomes confusos.
