# 📄 Requisitos do Sistema

## ✅ Requisitos Funcionais

Os requisitos funcionais representam o que o sistema deve fazer.

### RF01 — Autenticação de usuários
O sistema deve permitir login para acesso de usuários cadastrados.

### RF02 — Diferenciação de perfis
O sistema deve permitir diferentes perfis de acesso:
- professoras;
- secretaria;
- direção.

### RF03 — Cadastro de solicitações
O sistema deve permitir que professoras registrem novas solicitações internas.

### RF04 — Categorização das solicitações
O sistema deve permitir classificar os pedidos por categoria, como:
- material escolar;
- material de saúde;
- impressão/pesquisa;
- outros.

### RF05 — Descrição detalhada da solicitação
O sistema deve permitir que o usuário descreva o pedido com clareza.

### RF06 — Acompanhamento de status
O sistema deve permitir acompanhar o status da solicitação, incluindo:
- Aberta;
- Em andamento;
- Concluída;
- Cancelada.

### RF07 — Visualização de solicitações
O sistema deve permitir que a secretaria visualize todas as solicitações recebidas.

### RF08 — Atualização de status
O sistema deve permitir que a secretaria atualize o andamento de cada solicitação.

### RF09 — Histórico de solicitações
O sistema deve armazenar e exibir o histórico das solicitações realizadas.

### RF10 — Controle de acesso por perfil
O sistema deve restringir ações de acordo com o perfil do usuário.

### RF11 — Visualização administrativa
O sistema deve permitir que a direção acompanhe o fluxo das solicitações sem interferir diretamente no processo.

### RF12 — Registro de informações essenciais
O sistema deve manter os dados das solicitações de forma organizada para consulta futura.

---

## ⚙️ Requisitos Não Funcionais

Os requisitos não funcionais representam características de qualidade do sistema.

### RNF01 — Usabilidade
O sistema deve possuir interface simples e intuitiva, facilitando o uso por diferentes perfis de usuário.

### RNF02 — Responsividade
O sistema deve funcionar corretamente em diferentes tamanhos de tela, como computadores e dispositivos móveis.

### RNF03 — Segurança
O sistema deve proteger os dados dos usuários e restringir o acesso conforme o perfil.

### RNF04 — Organização
O sistema deve manter os dados estruturados de forma clara e acessível.

### RNF05 — Desempenho
O sistema deve responder de forma rápida às ações dos usuários, sem atrasos significativos.

### RNF06 — Confiabilidade
O sistema deve registrar corretamente as solicitações e preservar o histórico das ações.

### RNF07 — Manutenibilidade
O código deve ser organizado para facilitar ajustes, correções e futuras melhorias.

### RNF08 — Compatibilidade
O sistema deve ser compatível com navegadores web modernos.

### RNF09 — Disponibilidade
O sistema deve estar disponível para uso durante a rotina da escola, conforme a necessidade dos usuários.

### RNF10 — Versionamento
O projeto deve ser mantido em repositório Git/GitHub para controle de versões e colaboração da equipe.
