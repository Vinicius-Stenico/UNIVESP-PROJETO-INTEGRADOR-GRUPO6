# Sistema Web de Gerenciamento de Solicitações Internas para Secretaria de Escola Municipal

## 📌 Descrição do projeto

Este projeto consiste no desenvolvimento de uma aplicação web voltada ao gerenciamento de solicitações internas de uma escola municipal de educação infantil, localizada em Piracicaba - SP.

A proposta é digitalizar o fluxo de pedidos feitos pelas professoras à secretaria, permitindo que as solicitações sejam registradas, acompanhadas e organizadas de forma mais eficiente, substituindo a comunicação informal atualmente utilizada.

---

## 🎯 Objetivo

Desenvolver uma aplicação web responsiva para organizar, controlar e acompanhar solicitações internas da secretaria escolar, reduzindo a sobrecarga da equipe administrativa e melhorando o atendimento à comunidade escolar.

---

## 🧠 Problema que resolve

Atualmente, as solicitações internas da escola são feitas verbalmente ou por aplicativos de mensagem, como WhatsApp, sem um registro formal.

Isso gera problemas como:

- perda de informações;
- falta de controle sobre os pedidos;
- dificuldade para acompanhar o andamento das solicitações;
- retrabalho para a equipe da secretaria;
- sobrecarga das funcionárias responsáveis.

A aplicação busca resolver esse cenário por meio de um sistema centralizado, organizado e rastreável.

---

## ⚙️ Tecnologias utilizadas

- **Backend:** Python + Flask
- **Banco de dados:** MySQL
- **Frontend:** HTML, CSS responsivo
- **Versionamento:** Git e GitHub

---

## ✨ Funcionalidades principais

- Autenticação de usuários;
- Cadastro e registro de solicitações;
- Classificação por categorias;
- Acompanhamento de status:
  - Aberta;
  - Em andamento;
  - Concluída;
  - Cancelada;
- Perfis de usuário:
  - Professoras;
  - Secretaria;
  - Direção;
- Histórico das solicitações realizadas.

---

## 🛠️ Metodologia

O projeto foi desenvolvido com base na metodologia de **Design Thinking**, seguindo as etapas:

- **Ouvir:** levantamento de necessidades por meio de visita à escola e entrevistas;
- **Criar:** definição da proposta, funcionalidades e protótipo da solução;
- **Implementar:** desenvolvimento do sistema e validação da ideia com a comunidade envolvida.
