# 🖥️ Frontend

## 📌 O que é esta pasta?
Esta pasta contém a interface visual da aplicação, ou seja, tudo o que o usuário vê e utiliza no navegador.

## 📂 O que deve ser colocado aqui?
- Páginas HTML
- Arquivos CSS
- Arquivos JavaScript
- Componentes visuais
- Imagens e ícones
- Elementos de layout e responsividade

### Exemplos de arquivos:
- `index.html`
- `login.html`
- `solicitacoes.html`
- `style.css`
- `script.js`

## 🧠 Boas práticas
- Manter o código organizado e legível.
- Separar bem estrutura, estilo e comportamento.
- Usar nomes de classes e arquivos claros.
- Priorizar responsividade para computador e celular.
- Reutilizar componentes sempre que possível.
- Evitar misturar lógica de backend com código de interface.
